# Brand: فلاح (Falah)

The app's name is **فلاح** ("Falah"). It is the word from the adhan, حيّ على الفلاح, and it also means "farmer", which fits the farm that grows with each prayer.

- Home-screen name: فلاح
- Proposed App Store name: فلاح: صلِّ وازرع (English: Falah: Pray & Plant). Apps called "Falah" and "Falah App" already exist, so the store name needs the subtitle.
- Bundle IDs, targets and code names stay `Qawwam` for now. Renaming them is a separate change.

## Icon: نافذة الفجر (dawn window)

A mihrab arch as a window onto dawn, with a date palm in silhouette and a crescent at the top. No living beings are shown.

| File | Use |
|---|---|
| `falah-icon-light.svg` | Default icon source |
| `falah-icon-dark.svg` | iOS dark-mode icon source |
| `falah-icon-tinted.svg` | iOS tinted icon source (grayscale; iOS colours it) |
| `falah-wordmark.svg` | Arabic wordmark (Reem Kufi, outlined) |
| `falah-icon-final.png` | Overview sheet |

The 1024 px PNGs in `App/Assets.xcassets/AppIcon.appiconset` are exported from these SVGs.

Colours: green `#1F6B4F` / `#164D39`, gold `#E8A33A`, sand `#F1DDB0`, cream `#F5F0E6`.
